## 무엇이 바뀌었나
`node second-brain/tools/vault.mjs check` 가 W2 무결성 검사의 기계적 항목을 코드로 한다. 전에는 보이지 않던
기존 문제(id 중복, 끊긴 링크 등)가 처음 드러날 수 있다.

## 필요한지 판별
`check --json` 의 errors(code E1–E7)가 하나 이상이면 필요. 경고만 있으면 요약 한 줄만 보여 주고 불필요로 기록.

## 적용 방법
오류를 code 별로 묶어 보여 준다. 항목마다 고칠 방법(예: id 중복 → 새 번호 부여와 링크 수정)을 제안하고,
승인받은 것만 고친다. 경고는 "평소 정리는 '정리해'"로 안내만 한다.

## 승인 단위
오류 항목 하나씩 (같은 code 여러 개는 묶어서 한 번에 물어도 된다).

## 적용 후 확인
고친 파일에 대해 `check <파일>` 오류 0.
